**Автоформатирование кода**

Для автоматического форматирования кода на haskell наиболее распространёнными средствами являются `Ormolu` и `Fourmolu`. 

`Ormolu` - строгий форматтеров исходного кода. Он основан на библиотеке `ghc-lib-parser` и использует парсер `GHC` для анализа кода, что гарантирует, что он не сломает синтаксис и всегда будет совместим с последними версиями компилятора. Главная философия `Ormolu` - у него нет настроек. Он форматирует код `единственным правильным способом`, чтобы избежать споров в команде о стилях.

Чтобы отформатировать файл и сохранить изменения на месте нужно использовать флаг `-i`:
```shell
ormolu -i src/Main.hs
```

Если же нужно проверить, соответствует ли форматирование файла стандарту `Ormolu`:
```shell
ormolu --mode check src/Main.hs
```
Если код не отформатирован, команда завершится с ненулевым кодом возврата и покажет diff.

Поскольку `Ormolu` категорически отказывается предоставлять настройки (например, он всегда использует 2 пробела для отступов и специфичное расположение запятых), в сообществе родился его форк - `Fourmolu`. Консольные команды у него такие же, как у `Ormolu`.

Чтобы настроить `Fourmolu`, нужно создать файл `fourmolu.yaml` в корне проекта. `Fourmolu` автоматически найдет его.
Пример типичного `fourmolu.yaml`:
```yaml
# Количество пробелов для отступа (по умолчанию 4, в Ormolu всегда 2)
indentation: 4

# Стиль стрелок в функциях (leading, trailing, leading-args, trailing-comma)
function-arrows: trailing

# Стиль запятых (leading, trailing)
comma-style: leading

# Стиль запятых в импортах/экспортах
import-export-comma-style: trailing

# Пробел внутри фигурных скобок записей (Record syntax)
record-brace-space: true

# Стиль комментариев Haddock (multi-line, single-line)
haddock-style: multi-line

# Стиль let-выражений (auto, inline, newline)
let-style: auto

# Делать ли отступ для where (indent-wheres: true)
indent-wheres: false
```

Полный список опций можно посмотреть, выполнив `fourmolu --help`.

Иногда бывает нужно, чтобы форматтер не трогал специфичный кусок кода. `Fourmolu` поддерживает прагмы для отключения:
```haskell
{-# FOURMOLU_DISABLE #-}
myWeirdlyFormattedCode = 
  [ 1, 2,
    3,   4 ]
{-# FOURMOLU_ENABLE #-}
```

Если нужно исключить некоторые файлы (например, сгенерированные автоматами), нужно создать файл `.fourmoluiignore` (работает по аналогии с `.gitignore`) или передавайте файлы в CLI явно, а не указывая директории.
