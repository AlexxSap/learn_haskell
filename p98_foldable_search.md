**Поиск по Foldable коллекциям**

Класс `Foldable` абстрагирует идею сворачивания на коллекциях в одно значение. Почти все стандартные контейнеры являются `Foldable` и потому "из коробки" мы имеем богатый API для поиска.

Проверка наличия и условия:
- `elem :: (Foldable t, Eq a) => a -> t a -> Bool` - есть ли элемент в коллекции,
- `notElem :: (Foldable t, Eq a) => a -> t a -> Bool` - нет ли элемента,
- `any :: Foldable t => (a -> Bool) -> t a -> Bool` - существует ли элемент, удовлетворяющий условию,
- `all :: Foldable t => (a -> Bool) -> t a -> Bool` - все ли элементы удовлетворяют условию.

Поиск конкретного элемента:
- `find :: Foldable t => (a -> Bool) -> t a -> Maybe a` - находит первый (слева направо) элемент, удовлетворяющий предикату (`a -> Bool`).

Поиск экстремумов (минимум/максимум):
- `minimum :: (Foldable t, Ord a) => t a -> a` - поиск минимального элемента, и такая же для поиска максимума - `maximum`,
- `minimumBy :: (a -> a -> Ordering) -> [a] -> a` - поиск минимального элемента по функции сравнения и такая же для поиска максимума - `maximumBy`.

Проверка на пустоту:
- `null :: Foldable t => t a -> Bool` - пуста ли коллекция.

Важно понимать ограничения при поиске по `Foldable`-контейнерам - `Foldable` рассматривает коллекцию просто как набор элементов, игнорируя её внутреннюю структуру.
- Нельзя искать по ключу в `Map` или `HashMap` - экземпляр `Foldable` для `Map` сворачивает только значения, игнорируя ключи. Для поиска по ключу нужно использовать специфичные для `Map` функции (`Data.Map.lookup`),
- Нельзя искать по индексу - `Foldable` не гарантирует, что у коллекции есть индексы (например, у `Set` их нет),
- Нельзя искать подпоследовательности - `Foldable` не сохраняет порядок соседних элементов при свертке. Если это нужно, то используйте `Data.List.isInfixOf` или конвертируйте в список через `toList`,
- Нельзя эффективно искать в отсортированных коллекциях - свёртки всегда обходят структуру линейно (слева направо или справа налево). Даже если у нас отсортированный `Set` или `Vector`, вызов `find` или `elem` через `Foldable` будет иметь сложность O(N), а не O(log N). Для такого следует использовать специфичные функции, такие как `Data.Set.member`.
